OpenMCL — portable edition
==========================

Run OpenMCL.exe. Nothing is installed, and nothing is written to this
computer outside this folder.

Your worlds, mods, settings and accounts are kept in the OpenMCL-Data folder
that appears next to the executable, so copying this folder to another
machine takes everything with it.

FIRST RUN
---------
Windows will say "Windows protected your PC", because this build is not
code-signed. Click "More info", then "Run anyway".

Why: https://silocell.github.io/OpenMCL-Launcher/#first-run

BEFORE YOU CAN PLAY
-------------------
You need a Microsoft account that owns Minecraft: Java Edition, and a free
Microsoft application ID. Setup takes a few minutes, once:

  https://github.com/silocell/OpenMCL-Launcher#set-up-sign-in

A NOTE ON USB STICKS
--------------------
Minecraft writes to its game folder constantly. Running from a slow USB stick
works, but worlds will load faster from a hard disk or an SSD.
