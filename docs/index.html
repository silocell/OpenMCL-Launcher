One setup step before you play

Mojang only accepts sign-ins from registered applications, so OpenMCL cannot ship with a sign-in key of its own. You register a free Microsoft application and paste its ID into Settings. It takes a few minutes, once.

You also need a Microsoft account that owns Minecraft: Java Edition. The setup guide walks through every click.

What it does

The things a launcher is for, without the parts that get in the way.

Instances that stay separate

Own worlds, mods, configs, memory and Java version. Break one, the rest are fine.

Fabric, Quilt, NeoForge, Forge

Pick a loader when you make an instance. It installs itself, including Forge's patching step.

Mods from both places

Search Modrinth and CurseForge side by side, filtered to the version and loader you're actually running. Dependencies come along.

Modpacks in and out

Import .mrpack and CurseForge zips. Export any instance back out to share it.

Updates you can see coming

Check every installed mod against its newest build, then update the ones you want.

Make it yours

Three themes, any accent colour, per-instance settings for everything that matters.

Worth knowing first

Things people usually find out after downloading.

  • You need to own the game. OpenMCL checks your account owns Minecraft: Java Edition and won't launch otherwise. There is no offline or cracked mode, and there won't be one.
  • Windows will warn you. The build isn't code-signed, so SmartScreen shows “Windows protected your PC”. Choose More info, then Run anyway.
  • First launch is slow. The single-file build unpacks itself each time it starts. Build the folder version if that bothers you.
  • CurseForge browsing needs a free key. Modrinth works out of the box. Some CurseForge mods block third-party downloads entirely — OpenMCL tells you which and links you to the page.
  • It's version 0.1.0. Expect rough edges, and report them.
